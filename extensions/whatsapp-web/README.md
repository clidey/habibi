# Habibi WhatsApp Web Connector

Load this folder as an unpacked extension in Chrome or Chromium-based browsers:

1. Open `chrome://extensions` and enable Developer mode.
2. Choose **Load unpacked** and select this folder.
3. Keep your signed-in `web.whatsapp.com` tab open.

The connector reads only the visible Recents rows and sends their names, previews, timestamps, unread counts, and already-rendered avatar URLs to Habibi at `127.0.0.1`. It does not send data to any remote service.
