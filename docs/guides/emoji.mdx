# Emoji picker

Type **Emoji** in the launcher and press **Enter**. Browse a category or search
for a name or keyword such as `fire`, `party`, or `thanks`.

![Emoji picker with a selected winking face](/screenshots/emoji-picker.png)

## Choose and copy

Use the arrow keys to move through the grid. The selected emoji's details appear
with its copy action. Press **Enter** or choose **Copy** to place it on the
clipboard, then paste it into the app where you need it.

Successfully copied emoji appear in **Recent** on this Mac. Choosing an emoji
does not submit a chat message or send content to a provider.

## Variants

Where an emoji has a variant family, use its variant control or **Shift Enter**
to open the choices. Arrow keys move between them; Escape dismisses the variant
picker. The available glyphs also depend on the macOS version's emoji support.

## Keyboard flow

Keep typing in the scoped search field to narrow the grid, then use left, right,
up, and down to navigate the results. Escape returns from the picker when its
grid is focused. See [Keyboard shortcuts](/shortcuts) for the other workspaces.
