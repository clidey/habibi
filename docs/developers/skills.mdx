# Add a skill

A skill declares a capability and its permissions. It does not grant its own
authority or replace the host's approval policy.

## Start with a manifest

Create `skills/<id>/manifest.json`. A minimal read capability might look like:

```json
{
  "id": "scratchpad",
  "name": "Scratchpad",
  "version": "0.1.0",
  "kind": "native",
  "permissions": ["scratchpad:read"],
  "commands": ["search"]
}
```

This is an illustrative declaration, not a working integration. Register its
implementation and permission handling before exposing it to users.

`crates/habibi-local/src/skills.rs` defines the supported manifest fields and
kinds (`native`, `extension`, `local-service`, `oauth`) and validates every
manifest; a malformed one fails closed. Optional tool declarations identify read-only tools;
`requiresConfirmation` identifies commands that require the host's review flow.
A read-only hint never exempts an AI-invoked tool from user confirmation.

## Implement through the existing boundaries

1. Put the routes in the service crate that owns the area under `crates/`, or
   add a crate that implements `Routes` and register it in `habibi-server`.
2. Keep provider transport and normalization inside that service; reach other
   services only through the traits in `habibi-core`.
3. Put anything that differs per OS in `habibi-platform`, behind
   `cfg(target_os = ...)`, and return "unsupported" where it does not exist.
4. Model untrusted input with `serde` types and validate it in the route.
5. Expose reads, search, and preview preparation independently from execution,
   and add a write action to the approval allowlist.
6. Add a feature module beside `src/client/features/` and use Clidey UX controls.
7. Connect the feature through the composition root and add focused regressions
   in the owning crate.

Never send, write, or execute merely because a search result or model plan was
produced. An external write belongs in an explicit execution path with the
required fresh approval.

## Validate

```sh
pnpm run validate:manifests
pnpm run check
```

For a constrained external example, inspect the
[K9s read-only plugin](https://github.com/clidey/habibi/tree/main/plugins/k9s).
For UI and provider boundaries, see [Architecture](/developers/architecture).
