# Habibi

Habibi brings search, notes, conversations, and daily tools into a desktop
launcher for macOS, Windows, and Linux. Open it with **⌥ Space** (**Alt Space**
on Windows and Linux), type what you need, and press **Enter**.

## Start with what you need

- Find an app or file by name, or revisit something in **Recent files**.
- Write a note, track a reminder, start a focus timer, or read a script.
- Connect Mail, Calendar, WhatsApp, or WhoDB when you need that context.
- Configure a model to use **Ask Habibi**. Local models and supported hosted
  providers are available; everyday tools also work without a model.

## Where your data goes

Habibi is a desktop app with a Rust backend; it runs no local web server. Notes
and local history stay on your computer. Connecting an online service or submitting a request
to a hosted model involves that provider. See [Privacy](/privacy) for the details.

<Note>
  Habibi is an open-source alpha. macOS is the most complete platform. Windows
  and Linux builds compile and pass CI but have not yet been tested on real
  machines, and some features are macOS-only; see
  [Install Habibi](/getting-started/installation#platform-support).
</Note>
