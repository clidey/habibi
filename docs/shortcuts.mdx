# Keyboard shortcuts

Shortcuts apply to the active workspace. A text editor keeps its normal text
navigation and selection behavior.

| Where | Shortcut | Action |
| --- | --- | --- |
| Anywhere on this Mac | ⌥ Space by default | Open or close the launcher |
| Launcher | ↑ / ↓ | Navigate results |
| Launcher | Enter | Open the selected result or capability |
| Launcher | Escape | Go back or close |
| Search | Exact app name, then Enter | Open that built-in capability |
| Ask composer | ⌘ Enter | Submit the request |
| Notes | ⌘N | Create a page |
| Notes | ⌘F | Focus note search |
| Notes editor | ⌘K | Insert a link |
| Notes editor | `/` at block start | Open block commands |
| Notes editor | `[[` | Find a page to link |
| Notes command menu | ↑ / ↓, Enter, Escape | Choose or dismiss a command |
| Notes page list | ⌘-click / Shift-click | Select multiple pages |
| Emoji picker | Arrow keys, Enter | Choose and copy an emoji |
| Emoji picker | Shift Enter | Open available variants |
| Teleprompter editor | ⌘ Enter | Start reading |
| Focused teleprompter reader | Space | Pause or resume |
| Focused teleprompter reader | Escape | Close the reader |

Select text in Notes for contextual formatting. Standard editing shortcuts such
as **⌘B**, **⌘I**, **⌘U**, undo, and redo remain part of the editor experience.

Change the global launcher shortcut in [Settings](/settings). When a global
shortcut conflicts with another app, opening Habibi.app gives you a route back
to preferences even if its menu bar icon is hidden.
